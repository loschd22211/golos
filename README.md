# 🎙 Голос

**Офлайн-диктовка для Windows: говорите — текст появляется там, где стоит курсор.**

Нажали `Ctrl+Alt+Space`, сказали фразу, нажали ещё раз — текст вставился в активное
поле любого приложения: браузер, Word, Telegram, VS Code, 1С, поиск в Windows.
Русские и английские слова распознаются **вперемешку**: «сделай commit и push в GitHub»
так и запишется — кириллица кириллицей, английские термины латиницей.

Распознавание идёт **на вашем компьютере** (faster-whisper / OpenAI Whisper),
без интернета и без отправки голоса в облако. Интернет нужен только один раз —
скачать модель.

![Иконка](assets/golos.png)

Слева — обычный вид, справа — идёт запись и раскрыты дополнительные настройки:

![Окно программы](assets/preview.png)

## Возможности

| | |
|---|---|
| 🎤 **Запись с микрофона** | нажал — говоришь, нажал — текст вставился (`Ctrl+Alt+Space`) |
| 🌍 **Русский + английский вместе** | мультиязычная модель сама определяет язык, английские термины не переводятся |
| 📋 **Вставка в любое поле** | буфер обмена + `Ctrl+V` (или посимвольная печать — на выбор) |
| 🖱 **Работает в фоне** | иконка в трее, глобальные горячие клавиши, одно окно |
| 🪄 **Единое окно** | большая кнопка записи, живой индикатор уровня, последний текст, настройки применяются сразу |
| 🧠 **Whisper офлайн** | `tiny` → `large-v3`, CPU или видеокарта NVIDIA (CUDA) |
| 📝 **Свой словарь** | «питон → Python», «гитхаб → GitHub» — исправляет любимые слова |
| 🔇 **Фильтр тишины** | паузы и «э-э» не попадают в текст (по желанию) |
| 📊 **Журнал и история** | что распознано, сколько заняло, где ошибка |
| 🚀 **Автозапуск** | галочка в настройках — программа стартует вместе с Windows |
| 🔔 **Звук и уведомления** | слышно начало и конец записи, виден результат |

## Установка (Windows 10/11)

1. Установите [Python 3.10–3.12](https://www.python.org/downloads/windows/).
   При установке **обязательно** отметьте `Add python.exe to PATH`.
2. Скачайте проект (папкой или через `git clone`) в любое место,
   например `C:\Golos`.
3. Запустите **`run.bat`** — он сам создаст окружение `.venv`, поставит
   зависимости и запустит программу (первый раз это займёт несколько минут).
   В трее появится иконка микрофона.

Дальше для обновления и запуска достаточно двух команд:

```powershell
cd C:\Golos
git pull
.\run.bat
```

`install.bat` делает только установку (без запуска) и создаёт ярлык «Голос»
на рабочем столе и в меню «Пуск».

При первом распознавании скачается модель Whisper (для `medium` ≈ 1.5 ГБ).
Дальше интернет не нужен.

> Программа ничего не устанавливает в систему, кроме ярлыков и записи
> в `HKCU\...\Run`, если вы сами включите автозапуск. Удаление — просто
> удалить папку (и снять галочку автозапуска).

## Как пользоваться

| Действие | Клавиши |
|---|---|
| Начать запись | `Ctrl+Alt+Space` |
| Остановить и вставить текст | `Ctrl+Alt+Space` |
| Отменить запись (ничего не вставлять) | `Esc` |
| Пауза (клавиши не реагируют) | меню трея → «Пауза» |
| Настройки | правый клик по иконке → «Настройки…» |
| Выход | правый клик по иконке → «Выход» |

Файлы запуска:

| Файл | Что делает |
|---|---|
| **`run.bat`** | единая точка входа: ставит зависимости (если нужно) и запускает |
| `run.bat --debug` | то же, но с консолью и подробным журналом |
| `install.bat` | только установка + ярлыки |
| `doctor.bat` | диагностика: версии, пакеты, микрофоны, git, журнал → `diagnostic.txt` |

Окно программы открывается при каждом обычном запуске (`run.bat`). При
автозапуске с Windows программа стартует в фоне, только с иконкой в трее.
Открыть окно можно и из трея: правый клик по иконке → «Открыть «Голос»».

* большая кнопка — начать/остановить запись, она же показывает уровень микрофона;
* «Последний текст» — что распознано, с кнопками **Копировать** и **Вставить снова**;
* четыре быстрых настройки: модель, язык (Авто/Рус/Eng), микрофон, способ вставки;
* «⚙ Ещё настройки» — горячие клавиши, beam_size, свои слова, подсказка модели,
  VAD, автозапуск, история. Всё применяется **сразу**, кнопки «Сохранить» нет.

Порядок работы:

1. Поставьте курсор в нужное поле (в браузере, мессенджере, редакторе…).
2. `Ctrl+Alt+Space` — иконка в трее краснеет и показывает уровень громкости.
3. Говорите обычным темпом, можно вперемешку по-русски и по-английски.
4. `Ctrl+Alt+Space` — через секунду-две текст появится на месте курсора.

Иконка в трее показывает состояние: 🔵 готов · 🔴 слушаю · 🟠 распознаю ·
⏸ пауза · 🔴 ошибка. Наведите мышь — увидите подсказку и последний текст.

## Русский + английский в одной фразе

Whisper — мультиязычная модель: она распознаёт речь на языке, который слышит.
Поэтому «открой Docker и запусти Python-скрипт» превращается в тот же текст,
а не в перевод.

Что помогает точности:

* **Настройки → Распознавание → Язык: «Авто»** (по умолчанию).
* **Подсказка модели (initial prompt)** — уже заполнена примером смешанной речи.
  Допишите туда свои термины: названия проектов, сервисов, имена коллег.
* **Свои слова (hotwords)** — список через запятую: `Kubernetes, TypeScript, МойПроект`.
* **Словарь замен** — если модель упорно пишет «питон» вместо «Python»,
  добавьте пару `питон = Python`. Замена не зависит от регистра и не портит
  другие слова.
* Для смешанной речи лучше модель **medium** или **large-v3** — `tiny`/`base`
  чаще «переводят» английские слова в кириллицу.

## Выбор модели

| Модель | Размер загрузки | Скорость на CPU | Когда выбирать |
|---|---|---|---|
| `tiny` | ~75 МБ | мгновенно | быстрые заметки, но ошибок много |
| `base` | ~145 МБ | очень быстро | короткие команды |
| `small` | ~480 МБ | быстро | ноутбук без GPU, простые фразы |
| `medium` | ~1.5 ГБ | средне | **рекомендуется**: точность + смешанный язык |
| `large-v3` | ~3 ГБ | медленно без GPU | максимум точности, лучше с видеокартой |

Если есть видеокарта NVIDIA с CUDA — в настройках оставьте
**Устройство: auto**: программа возьмёт GPU (`float16`), иначе CPU (`int8`).
Смена модели применяется сразу, новая скачается в фоне.

## Настройки

Все параметры — в одном окне, изменения применяются сразу и сразу пишутся в
`%APPDATA%\Golos\config.json`.

| Где | Что настраивается |
|---|---|
| Главное окно | модель, язык, микрофон, способ вставки, пробел в конце, заглавные буквы, звуки, уведомления |
| ⚙ Ещё настройки | горячая клавиша (можно «записать» нажатием), клавиша отмены, beam_size, свои слова, подсказка модели, фильтр тишины, автозапуск, предзагрузка модели, история |
| Меню трея | начать/остановить запись, пауза, история, журнал, папка настроек, выход |

Остальные параметры (частота дискретизации, минимальная длина записи, задержка
вставки, замена слов) доступны в `config.json` — они меняются редко, поэтому
в окно не вынесены.

## Файлы и приватность

```
%APPDATA%\Golos\config.json   настройки
%APPDATA%\Golos\golos.log     журнал (ротация 1 МБ × 3)
%APPDATA%\Golos\history.txt   история диктовок (можно отключить)
%APPDATA%\Golos\models\       скачанные модели Whisper
```

* Аудио **не сохраняется** на диск и **никуда не отправляется** — обрабатывается
  в памяти и забывается после вставки текста.
* Единственный сетевой запрос — скачивание модели с Hugging Face при первом
  использовании выбранной модели.

## Если что-то не работает

**Запустил `run.bat` — и ничего не произошло**
Скорее всего программа **уже работает** (второй запуск ничего не открывает) или
её иконка спрятана в трее. Что делать:

1. Посмотрите в трей рядом с часами. Windows 11 прячет новые иконки: нажмите
   стрелку **`^`** слева от часов и перетащите микрофон на панель.
2. Правый клик по иконке → **«Открыть «Голос»»**.
3. Если иконки нет — проверьте процессы:
   `Get-Process pythonw -ErrorAction SilentlyContinue`
4. Полная диагностика одной командой:

```powershell
cd C:\Users\user\Downloads\golos
.\doctor.bat
```

Скрипт соберёт версии, пакеты, микрофоны, состояние git и последние строки
журнала в файл `diagnostic.txt`.

**После `git pull` интерфейс не изменился**
Обновлённый код подхватывается только при новом запуске. Правый клик по иконке
в трее → **«Выход»**, затем снова `run.bat`. Если окно так и осталось старым,
проверьте, что вы на нужной ветке:

```powershell
git log -1 --oneline     # ожидается коммит с новым окном (golos/ui.py)
git branch --show-current
```

**«Не удалось назначить горячую клавишу»**
Сочетание занято другой программой (часто это NVIDIA/Overwolf/мессенджеры).
Выберите другое в настройках, например `Ctrl+Shift+Space` или `F9`.

**Микрофон молчит**
Параметры Windows → Конфиденциальность → Микрофон → разрешить приложениям
доступ к микрофону. В окне программы выберите микрофон в списке и нажмите ↻,
чтобы обновить список устройств.

**Текст не вставляется**
Активное окно запущено от имени администратора, а «Голос» — нет. Запустите
программу от администратора (или наоборот, приложение — от обычного
пользователя). Помогает и переключение способа вставки на «Посимвольно».

**Английские слова превращаются в кириллицу**
Возьмите модель побольше (`medium`/`large-v3`), добавьте термины в «Свои слова»
и в подсказку модели, либо используйте словарь замен.

**Медленно распознаёт**
Выберите модель меньше (`small`), оставьте `beam_size = 5`, отключите CUDA,
если видеокарта старая. 10 секунд речи на `medium`/CPU — примерно 3–6 секунд.

**Первая диктовка долгая**
Модель загружается в память (у `medium` — 5–20 секунд). Включите
«Загружать модель сразу при запуске» в «Прочее», если это раздражает.

**Антивирус ругается**
`keyboard` перехватывает глобальные клавиши — некоторые антивирусы считают это
подозрительным. Добавьте папку программы в исключения.

## Запуск из исходников / разработка

```bash
# самый простой путь
.\run.bat

# или вручную
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python golos_app.py             # обычный запуск
python golos_app.py --debug     # с подробным журналом в консоли
python golos_app.py --no-gui    # без трея: текст печатается в консоль
```

Аргументы командной строки:

| Аргумент | Что делает |
|---|---|
| `--show` | сразу открыть окно программы |
| `--silent` | в фоне: без консоли и без окна (используется автозапуском) |
| `--status` | проверить, запущен ли «Голос» (0 — да, 1 — нет) |
| `--no-tray` | без иконки в трее |
| `--no-gui` | полностью без интерфейса |
| `--no-preload` | не загружать модель при старте |
| `--config PATH` | свой файл настроек |
| `--debug` | уровень журнала DEBUG |
| `--version` | версия |

Тесты (не требуют Windows, микрофона и модели):

```bash
pip install -r requirements-dev.txt
python -m pytest -q      # 108 тестов, меньше секунды
```

Структура:

```
golos/
  app.py              ядро: запись → распознавание → вставка, состояния, статистика
  audio.py            запись с микрофона (sounddevice), обрезка тишины, ресемплинг
  transcribe.py       faster-whisper: ленивая загрузка модели, авто-язык
  textproc.py         чистка текста: пробелы, регистр, склейка алфавитов, замены
  inject.py           вставка: буфер обмена + Ctrl+V или посимвольная печать
  hotkeys.py          глобальные клавиши (keyboard) + нормализация сочетаний
  config.py           dataclass настроек, JSON, валидация значений
  system.py           один экземпляр, автозапуск через реестр, звуки
  tray.py             иконка в трее (pystray + Pillow), меню, уведомления
  ui.py               единое окно (tkinter): кнопка записи, уровень, настройки
golos_app.py          точка входа: трей + tkinter-цикл + маршрутизация событий
run.bat / install.ps1 установка и запуск одной командой
doctor.bat            диагностика окружения → diagnostic.txt
tests/                108 тестов: логика, окно на фейковом tkinter, сквозной сценарий
```

Ядро (`DictationApp`) не зависит от GUI: интерфейс подписывается на события
через `UiBridge`, поэтому диктовку можно тестировать с фейковым микрофоном и
моделью.

## Ограничения

* Только Windows (10/11). Код почти кроссплатформенный, но глобальный перехват
  клавиш и автозапуск реализованы под Windows.
* Одна запись за раз, распознавание последовательное.
* Нет потокового вывода «по словам»: текст появляется после остановки записи.
* Приложения, блокирующие эмуляцию клавиатуры (некоторые игры, «безопасный
  ввод» банков), текст не примут — это ограничение самой программы.
